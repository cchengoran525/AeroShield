# 0002. 中翼储物羽:人电混合驱动(电子弹出挂钩,人手开羽)

- 日期:2026-10-11
- 状态:已采纳(交互模型用户定案;实现细节待实物验证)
- 关联:README §6.2(挂钩二级传动)、§11(技术路线)、ADR 0001;electronics/README.md(双脑架构)

## 背景

中翼每边 4 根大储物羽,需要**取哪根里的东西就开哪根**(真·独立访问)。若每自由度一个舵机:翼根 2 自由度 + 4 羽 = 每边 6 个、一对 12 个,重量、走线、供电全爆;若用分档转鼓(1 舵机/边),牺牲独立性——不能"只开第 3 根"。

用户定案交互模型:**挥手/触碰 → 挂钩弹出 → 人拉挂钩,机械二级机构开羽(功来自人)→ 人推合羽 → 电子复锁**。独立访问由人手选择实现,电子不驱动开羽动作。

## 备选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 每羽一舵机(4/边) | 真·轨迹控制,可编排缓动展开 | 12 舵机/对,重量走线供电不可接受 |
| B. 分档转鼓(1/边) | 1 舵机管 4 羽,可级联缓动 | 失去独立性,不能只开指定羽 |
| C. 电磁锁独立释锁(4/边) | 真·独立、脉冲驱动、静音 | 只开不关(合羽仍需人),4 路电流脉冲,猛弹开显廉价 |
| **D. 挂钩弹出 + 人手开羽(采纳)** | 执行器最少(1/边),独立访问零执行器成本,人手速度=开羽速度,符合 §6.2 | 开羽无"自动优雅慢开";挂钩弹出需要感知触发;需复锁机制 |

## 决策

选 D。每边 **1 个微型舵机驱动共享保持杆**(凸轮式),平时把 4 根弹簧挂钩压平隐藏;感知到挥手/靠近后保持杆退开,挂钩弹出自锁在外侧;人握挂钩向外拉,经 README §6.2 二级机械行程开羽开储物口;储物羽推回闭合位(背板微动开关确认)后,保持舵机重新压回保持杆复锁。

电子的三件事:**感知**(APDS-9960 接近/挥手,触发弹出)、**确认**(背板微动开关,确认闭合)、**复锁**(保持舵机回位)。开羽的功 100% 来自人手。

## 理由

- **机械优先**(原则四)的本意:电子只做"释放与确认",力传导全部交给机械+人力——这是比 ADR 0001 方案 C 更彻底的执行;
- **人是选择器**:独立访问不需要电子分辨"要开哪根",人的手伸向哪根就开哪根,电子零成本获得独立性;
- **减负是底线**:相对方案 A 省 8 个舵机/对(约 80–100g),相对 C 省电磁铁与驱动板;
- 挂钩兼任三重角色:拉手(人机接口)、弹簧自锁(机械)、触摸电极(未来 v2,零成本升级位)。

## 后果

- 跨关节走线为零:挂钩不接线,电子全部留在背板(微动开关是静态布线);
- 储物羽不承担"自动优雅展开"的表达功能——表达性动作由翼根展收 + 覆羽级联承担(功能分区);
- 复锁依赖闭合检测:8 个微动开关(每羽 1 个)上背板,v2 可换电容检测;
- 挥手误触发代价低(挂钩弹出无害),配 20s 无操作自动收回复锁的宽容环;
- 重新打开本决策的条件:若 demo 实测"人拉开羽"体验生硬(拉力过大/行程不顺),则重评 B 方案(转鼓)+ 小舵机辅助。
