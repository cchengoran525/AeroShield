# 0001. 机电一体：电子参与动作，机械优先原则演进

- 日期：2026-08-30
- 状态：已采纳
- 关联：README §11（技术路线）、docs/roadmap.md §4

## 背景

根源文档 v0.1 的表述是"机械负责产生自然动作，电子负责理解人体状态"。但 AS 的核心交互范式是**动作自动完成**（人不操作翅膀，翅膀理解人体后自行动作）——自动动作必然需要执行器参与，纯被动机械无法实现"感知→响应"。

## 备选方案

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 纯机械产生动作（电机仅辅助） | 轻、可靠 | 无法实现自动触发动作，demo 无法表达"人不操作翅膀" |
| B. 电机全权驱动每个自由度 | 控制灵活 | 违背根源：堆电机、重、"机器人感" |
| C. 电机给主驱动，机械给动作质感 | 兼顾自动性与自然性 | 需要软硬协同设计动作轨迹 |

## 决策

选 C。每片翼只保留**一个电机驱动的主自由度**；"自然动作"的质感由机械结构（连杆轨迹、拉簧回位、羽毛被动级联铺开）与软件缓动曲线（缓入缓出）共同实现；传感器 + 状态机负责理解人体并触发动作。

## 理由

不违背根源原则四"机械优先"的本意——它反对的是**堆电机硬怼自由度**，而不是反对电机本身。"减负是底线"在 1/6 缩比阶段体现为：每增加一个执行器，必须先回答它带来的表现力是否值这个重量与复杂度。

## 后果

- "机械产生自然动作"的落点从"驱动机构"转移为"质感机构"（级联、回位、锁止）
- 电子物料清单提前到 Phase 1 即需采购（ESP32 + 舵机 + IMU）
- Phase 2 下层翼的 110° 锁止仍走纯机械锁止 + 电机解锁路线，不受本决策影响
