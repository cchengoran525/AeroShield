# Force-line Analysis —— 力学传导路径分析

> 落地 [README §12.1](../README.md)。
> 目标：证明 AS 的结构不是把重量"挂"在人身上，而是在**重新组织人体与机械之间的受力关系**。

## 设计传导路径（根源定义）

```
翼载荷 → 背板 → 中 / 下层结构 → 髋部 → 骨盆 / 股骨
```

思想对标登山包腰带：不是让重量消失，而是改变重量作用于人体的方式。

## 分析维度（待原型验证后逐项填写）

- [ ] 重心：整机（人 + 翼 + 载荷）合成重心相对人体重心的偏移
- [ ] 力矩：各翼区载荷对肩关节 / 髋关节的力矩
- [ ] 支撑点：背板与人体接触面、髋部承重接口的位置
- [ ] 局部压力：肩带 / 背板 / 腰带处的压强分布
- [ ] 结构受力：背板与下层的传力构件应力路径
