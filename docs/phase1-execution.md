## ⓪ 全局技术决策（开工即定死，半年不改）

| 项 | 选定 | 关键参数 |
|---|---|---|
| 主控 | ESP32-WROOM-32 开发板（30pin） | Arduino 框架 + PlatformIO |
| 舵机 | MG90S ×2 + 备 1 | 2.2 kg·cm @4.8V，金属齿，9g，速度 0.1s/60° |
| IMU | GY-521 (MPU6050) | I2C 地址 0x68，±2g/±250° 默认量程 |

| 供电 | 测试期 USB 5V/2A；电池期 103450 锂电 1000mAh + MT3608 升压 | 舵机与 ESP32 **分路供电、共地**，舵机电源端并 470μF 电解 + 100nF 陶瓷 |
| 舵机驱动 | ESP32 LEDC 硬件 PWM | 50Hz，脉宽 500–2500μs ↔ 0–180°，每 20ms 一帧插值（微步缓动） |
| 打印 | PLA，0.4 喷嘴 | 外壳件 0.2 层厚；铰链/槽/柔性件 **0.12 层厚**；孔公差按试条标定（默认孔放大 +0.25mm） |
| 翼尺寸 | 单侧展开长 ~150mm，弦 ~70mm | 收拢贴背，展开仰角约 30–45° |

固件三层架构从 M1 立好，M6 不重构：`传感层（采样+滤波+阈值）→ 状态机（IDLE/NEAR/LIFT/BRIGHT…）→ 动作层（关键帧队列 + 缓动插值）`。

首轮物料清单：MG90S×3、ESP32 30pin、GY-521、GL5528、MT3608、103450 电池、470μF/100nF 电容、面包板杜邦线、M2 自攻螺丝一套；打印机备件同批买：喷嘴×3、PTFE 管、皮带。

## M1 · 9月：单翼四杆机构打通

### 周1（8/31–9/6）链路 + 公差手感

**做**：
1. 下单物料（清单见 ⓪）。
2. 打**公差试条**：一块板上 5 对轴-孔配合（间隙 0.10/0.20/0.30/0.40/0.50）+ 2 对压配（0.05/0.08），销径统一 2.0mm。掰、转、拔，记录手感，填出本打印机**公差表**：活动铰链用哪档、压配用哪档。这张表是之后所有机构的输入参数。
3. 一晚打通链路：LEDC 50Hz 驱动舵机，串口发角度；MPU6050 读原始加速度模值 |a|，对比静置 vs 拿起读数，写死第一版阈值。

**知识**：
- FDM 孔**实际偏小 0.1–0.3mm**（挤出堆积 + 热收缩，圆周方向挤出路径重叠），孔永远预放大；轴受热垂坠偏粗，立着打。
- MG90S 信号高电平判定 ~2.4V，ESP32 的 3.3V 直驱没问题，不需要电平转换。

**交付**：公差表照片 + "拿起→舵机摆动"10 秒视频。

### 周2（9/7–9/13）四杆机构设计（机械第一课）

**做**：不做舵机直掰，而是**舵机 + 曲柄摇杆四杆**驱动翼根：
1. GeoGebra（或纸上）几何综合：机架 L1 = 舵机轴到翼根轴距离（取 35–45mm）；曲柄 r = 15–20mm（舵机臂）；摇杆 r2 = 10–12mm（翼根臂）；连杆长度解出。
2. 目标特性：舵机转 60° → 翼根转 110–120°（角度放大比 ≈ r/r2 + 曲柄摇杆非线性增益），且展开末段摇杆角速度自然递减——"先快后缓"的机械来源，代码缓动只是叠加。
3. 校核两件事：**传动角 γ**（连杆与摇杆夹角，全行程 >40°，γ 小则传力差、机构"虚"）；**死点**（连杆与摇杆共线位置必须落在行程之外）。
4. Fusion 装好后 agent 代建参数化模型（L1/r/r2/连杆长全部做成用户参数），孔径用周1公差表，打第一版。

**知识**：
- **Grashof 条件**：最短杆 + 最长杆 ≤ 其余两杆之和，且最短杆作曲柄 → 曲柄摇杆机构。这是选杆长的硬约束，违反就卡死。
- 四杆的"免费好处"：摇杆在极限位置附近角速度天然趋零，等于机构内置了一段 easeOut。

**交付**：手动拨动全行程无死点无干涉视频 + 四杆参数表（L1/r/r2/连杆长/行程角）。

### 周3（9/14–9/20）缓动固件 + 触发算法

**做**：
1. 缓动核心：每 20ms 算一次 `pos = start + (end-start) × ease(t/T)`。三档对比录像：
   - `easeInOutCubic`：`p<0.5 ? 4p³ : 1-(-2p+2)³/2` —— 展开主力
   - `easeOutBack`（过冲回弹，s=1.70158）—— "甩开"感，慎用，幅度大显得玩具
   - linear 600ms vs cubic 900ms —— 建立"匀速=机器、缓动=生物"直觉
2. IMU 触发定版：滑动均值（窗口 5）→ **双阈值迟滞**（|a| >0.30g 触发 LIFT，<0.15g 解除）→ 触发后 1s 不再判。测 20 次"拿起"，要求 20/20。
3. 防坑：舵机运动振动会被 IMU 读到——**动作期间挂起 LIFT 判定**（状态机加 MOVING 屏蔽位）。

**知识**：单阈值必坏——噪声在阈值附近反复穿越，输出抖成方波；迟滞是所有实测传感触发的标准形态。

**交付**：三缓动对比视频 + 20/20 触发测试记录。

### 周4（9/21–9/27）M1 集成验收

**做**：翼上支架，完整循环"静置→拿起→弧线展开→放下→收拢"；Fusion 源 + STL + 固件打 tag **v07**（机电同号第一次执行）；journal 记录设计翼根行程 vs 实测行程偏差（四杆制造误差，通常 3–8°，是 M3 软件标定的原因）。

**验收**：一片翼沿弧线自动展开，能指着机构说出曲柄/连杆/摇杆/机架各是哪个。

## M2 · 10月：羽毛级联（槽机构）——高考月

### 周5（10/1–10/7）布局与槽选型

**做**：
1. 羽毛布局定版：单侧 **5 根**（3 显秃，7 装配量翻倍），长 60→110mm 梯次，叠序**上层压下层**（收拢时像瓦片）。
2. 槽机构：每根羽毛根销走**弧形槽**，槽前段空程——翼根转过 θ₀ 后依次带动第 1、2、3…根。空程梯度 δ 取 **8–10mm/根**。
3. 打**槽宽试条**：一块板 6 种槽宽（1.0/1.2/1.5/2.0mm）配 2.0mm 销，实测滑动阻力，选"阻力小且无明显旷量"档（经验 1.2–1.5mm 中选）。

**知识（级联延迟可以算）**：翼根角速度 ω → 销线速度 v = ω×r（r 为销到翼根轴距离）→ 第 i 根羽毛启动延迟 tᵢ = δᵢ/v。展开全程 0.9s、r≈30mm 时，8mm 空程 ≈ 80–120ms 级联梯度——正落在真实猛禽羽级联（50–150ms）区间。**参数不是玄学，是几何。**

**交付**：槽宽选型结论 + 羽毛布局图。

### 周6–7（10/8–10/20）级联翼迭代 3–4 轮

**每轮打印做参数阵列**（一块板 4–6 个变体，不是一轮一个）。固定诊断表按症状对号：

| 症状 | 病因 | 处方 |
|---|---|---|
| 羽毛到位后回弹 | 槽末端无挡 | 末端加挡销或封闭槽端 |
| 级联不齐、某根抢跑 | 销孔位置误差累积 | 销孔放大公差、槽长 +0.5mm 冗余 |
| "哗啦"一下全展开 | 空程梯度太小 | δ 从 8→10mm |
| 中段羽毛翘起 | 叠层接触不足 | 叠面加 0.4mm 凸点垫 |
| 滑动涩 | 层纹方向 = 滑动方向 | 槽板打印方向转 90°，或摩擦面贴 PTFE 胶带 |

同时：找红隼/猫头鹰展开慢动作视频，**逐帧数羽毛启动相对延迟**，把生物值标定进 δ 梯度。

**验收（月末）**：展开总时长 0.8–1.2s，逐帧有明显级联；给不懂的人看 10 秒，第一反应"翅膀"而非"机械臂"。追问"哪里不像"记进 journal，能改的进 M3。

**交付**：级联展开视频 + 猛禽对照笔记。

### 周8（10/21–10/27）光敏触发 + 状态机扩容

**做**：GL5528 分压进 ADC，100Hz + 滑动均值，手机手电筒 10cm 距离标定强光阈值（遮阳演示触发源）。状态机扩为 4 态（IDLE/NEAR/LIFT/BRIGHT）→ 动作映射表——**这张表就是 pose-matrix 的固件化身**，文档矩阵与固件映射一一对应，改一处同步另一处。

**交付**：M2 全量验收视频；pose-matrix 3 行更新"已实测"；ADR 0002 落笔（槽机构级联，记 δ 梯度与选型理由）。

## M3 · 11月：成对 + 背板集成

### 周9（11/2–11/8）双翼与"不完美对称"

**做**：右翼零件 Fusion 镜像导出打印。装完**左右标定**：正对机位拍展开停格，量两翼尖高度差，软件给每侧角度 offset ±3–5° 修正（同型号舵机同指令角差 2–5° 正常）。加一个反直觉参数：**右翼动作延迟 60–120ms**——完美同步是机器，生物两侧永远差半拍，此参数对活物感贡献极大。

### 周10（11/9–11/15）动作库

**做**：动作数据结构定版：`帧 = {左目标角, 右目标角, 时长ms, 缓动类型}`，动作 = 帧数组（Phase 2 直接沿用，本项目最重要软件资产）。落 6 个：展开问候 / 收拢 / 遮阳姿态（展开+上仰 15°）/ **呼吸微动**（±2°、周期 4s 极缓正弦，静置"活着"的全部秘密，成本零）/ 拿起应急收拢 / 开机自检。写**打断逻辑**：动作执行中收到新指令，从当前角度反向缓动，绝不硬跳（硬跳=瞬间满速=机械感+堵转风险双杀）。

### 周11–12（11/16–11/29）背板集成（电子用户主导）

**做**：
1. v06 外壳内布局：ESP32 底部、双舵机左右、GY-521 **贴壳内侧但离舵机 ≥20mm**。
2. 振动耦合是头号敌人：舵机 50Hz PWM 及谐波正落 MPU6050 带宽内，动作期 IMU 读数被调制。三重防线：物理减振（EVA 泡沫垫）→ 动作期挂起判定（M1 已做）→ 判定升级为**加速度模值 AND 角速度模值同时超阈**（振动只调加速度谱，真实拿起两个都动）。
3. 跨关节走线：每根线留 U 形服务环（活动路径最长长度 +15mm），热缩管 + 扎带。面包板退役，洞洞板焊接或飞线。
4. 轨迹数据闭环（用户舒适区 × 机构新玩法）：正对+侧面双机位视频追翼尖位置，画**实际展开角速度曲线 vs 设计曲线**，回微四杆相位安装角。此能力 Phase 2 直接复用。

**交付**：整单元 USB 供电独立跑全部 6 动作；v09。

## M4 · 12月：人偶集成 + 稳定性

### 周13（11/30–12/6）重心之战

**算**：单侧翼展开力矩 ≈ 35g × 80mm ≈ 280 g·cm，双侧 560 g·cm 作用于背上部；1/6 人偶（300g 级）站立支撑多边形只有两只脚掌。翻倒判据一条：**人+翼合力作用线是否穿出脚掌支撑多边形**。

**对策按序（先无成本的）**：① 翼根安装点**前移 10mm**（力臂减 ~25%，可能就够）→ ② 素体脚底配重 40g 铅片 → ③ 隐形底座（透明亚克力插脚）。MVP 推荐直接 **3D 打印固定姿态人偶 + 底座**，避开可动素体关节松垮，demo 又不需要人偶摆 pose。

### 周14（12/7–12/13）电池化

**做**：103450 + MT3608 升压。实测功耗画像：静置 ~120mA、动作峰值 ~0.9A，理论续航 ≈ 1000mAh / 平均 250mA ≈ 3.5h（拍摄日足够）。**brownout 复位**（舵机启动浪涌把电压拽到 <2.8V，ESP32 自动复位）用 470μF + 分路供电解决；仍出现则 MT3608 输出再并 1000μF。

### 周15–16（12/14–12/27）稳定性 ×3 轮（含假期损耗缓冲）

**做**：30 分钟自动演示循环 ×3，盯三类问题各配诊断口诀：
- 死机 → 事后接串口读 **reset reason 寄存器**（看门狗/内存/掉电一眼分辨）
- 误触发 → 统计 30min 误触发次数，目标 <1；超标回 M3 三重防线收紧阈值
- 舵机温升 → 红外/手指测温 <50℃；过热 = 机构阻力大或保持力用满，回公差表查配合过紧

同时开始素材积累：每周随手拍 3–5 条试验镜头进 `media/photos/`（M5 会感谢现在）。

## M5 · 1月：90 秒短片

### 周17（12/28–1/4）分镜

结构定版：**静置呼吸 8s（建立"它是活的"）→ 走近打招呼展开 20s（主场景）→ 强光遮阳 20s → 拿起收拢互动 20s → 定格+标题 20s**。每场景一页参数表：机位/光位/动作速度档/触发方式（**拍片用预设时序更稳，感知触发留给互动环节**）。

### 周18–19（1/5–1/18）拍摄

三条纪律：
1. **暗背景 + 侧逆光**：羽毛轮廓发光、层纹消失。一盏台灯 + 白墙 = 免费影棚。
2. **配乐盖舵机且反过来用**：选 70–90 BPM 曲子，动作时长取整拍（70BPM 一拍 ≈ 0.86s，M2 调的 0.9s 展开正好卡拍——可以反过来调动作参数凑音乐）。
3. 手机 1080p60 拍，后期可放慢 40% 依然顺滑；每镜头 3 条起；动作速度两档预设固件切换。

### 周20（1/19–1/25）剪辑 + 文档

剪映够用：粗剪定节奏 → 调色（统一冷暗底 + 暖高光）→ 字幕极简。文档三件：pose-matrix 全表实测更新、ADR 0003（供电架构）、journal 复盘 M2–M5 实际耗时 vs 计划。
