# S3(感知脑)→ ESP32(动作脑)UART 协议 v0

> 物理层:UART 115200-8N1,3.3V TTL 直连(TX=17/RX=18 @S3,TX=18/RX=19 @ESP32),共地。
> 设计原则:动作脑只认状态,不碰原始信号;帧短(≤12B)、低频(≤20Hz)、带 CRC、可双向。

## 1. 帧格式(固定)

```
┌──────┬──────┬─────┬──────┬─────────┬──────┐
│ 0xAA │ 0x55 │ LEN │ TYPE │ PAYLOAD │ CRC8 │
└──────┴──────┴─────┴──────┴─────────┴──────┘
```

- LEN = TYPE 起到 CRC 前的字节数(含 TYPE,不含头);
- CRC8 多项式 0x07,初值 0x00,计算范围 TYPE→PAYLOAD;
- 解析态机按 0xAA 0x55 对齐,CRC 错整帧丢弃、计数进遥测,不重传(低频状态流,丢一帧无所谓)。

## 2. 帧类型

### S3 → ESP32

| TYPE | 名称 | 周期 | PAYLOAD |
|---|---|---|---|
| 0x01 | STATE | 10–20Hz | `state`(u8 位掩码)+ `conf`(u8 0–100) |
| 0x02 | VITALS | 1Hz | `hr`(u8)+ `hr_conf`(u8)+ `t_skin`(u16,0.1℃)+ `t_amb`(u16,0.1℃)+ `hum`(u8,%) |
| 0x03 | EVENT | 异步 | `code`(u8)+ `param`(u8) |
| 0x04 | BATTERY | 每 10s | `pct`(u8 %)+ `mv`(u16) |

**STATE 位掩码**(与 docs/pose-matrix.md 一一对应,改一处同步另一处):

| bit | 状态 | 阈值判定在 S3 就地完成 |
|---|---|---|
| 0 | NEAR 有人靠近 | ToF < 阈值 + 迟滞 + 300ms 驻留 |
| 1 | LIFT 拿起/移动 | 加速度 AND 角速度双模值(ADR 0001 M3 防线) |
| 2 | BRIGHT 强光 | 光敏(过渡期由动作脑自采,稳定后移交) |
| 3 | HEAT 背部闷热 | 贴身温/湿超阈,迟滞 0.5℃/5% |
| 4 | SQUAT 微蹲 | IMU 姿态角 + 角速度窗口 |
| 5 | FATIGUE 劳累倾向 | 心率趋势(远期,暂不置位) |
| 6 | HAND_UP 举手/挥手 | IMU 上肢耦合特征(过渡期由 APDS 代管) |

**EVENT code**:0x01 approach_start / 0x02 approach_end / 0x03 tap / 0x04 squat_enter / 0x05 squat_exit / 0x10 sensor_fault(设备号入 param)。

### ESP32 → S3

| TYPE | 名称 | PAYLOAD |
|---|---|---|
| 0x11 | ACK | 最近收到的 seq |
| 0x12 | SET_THRESHOLD | `id`(u8)+ `value`(u16)——调参台下发,断电不保存(易失) |
| 0x13 | SET_MODE | 0=自动 1=演示时序 2=静默;掉电回自动 |
| 0x14 | LED | RGB 三字节,转发板载 WS2812 |

## 3. 降级与看门狗(定死参数)

| 场景 | 参数 | 动作 |
|---|---|---|
| 动作脑 500ms 无任何帧 | 帧间隔看门狗 | 进 SAFE:回 IDLE + 呼吸微动,风扇维持 HEAT 逻辑, **绝不中途冻住动作** |
| S3 连续 3 次 300ms 无 ACK | 发送超时 | 判动作脑离线,BLE 广播告警,LED 红 |
| S3 本身死机 | 硬件看门狗 | 动作脑侧 500ms 静默兜底(同上) |
| CRC 错帧 | — | 丢弃 + 遥测计数;串口/网页控制台可见 |

SAFE 态铁律:安全态是**回到静置行为**,不是断电冻结——收拢到 IDLE 位形,保持呼吸微动。

## 4. 调参闭环

SET_THRESHOLD(0x12)由 S3 的网页调参台下 发(阈值 id 表在 S3 固件内维护),**易失**——标定完成后的数值由人回填进固件默认值表(与 phase1-execution"活文档回填"同一纪律),避免闪存写寿命和配置漂移。
