# 引脚分配与接线地图(双脑架构 v0)

> 动作脑 = ESP32-WROOM-32 38pin DevKit(现有板);感知脑 = ESP32-S3-WROOM-1 DevKitC。
> v1 = 本轮定案;标注 [v2] 的为预留升级位,不接线。日期 2026-10-11。

---

## 1. 动作脑 ESP38(中翼一对 + 散热)

| 功能 | GPIO | 备注 |
|---|---|---|
| 翼根展收舵机 L / R | 25 / 26 | LEDC 50Hz;避开全部触摸通道(留 v2) |
| 挂钩保持舵机 L / R | 16 / 17 | LEDC 50Hz;微型舵机 |
| 散热风扇 ×2(MOSFET) | 23 / 5 | LEDC 25kHz,非 50Hz;GPIO5 为 strap,上电默认拉低即可 |
| UART2 → 感知脑 | TX=18, RX=19 | GPIO 矩阵重映射,不占默认 16/17 |
| I2C0(APDS-9960) | SDA=21, SCL=22 | 地址 0x39 |
| 光敏 GL5528 | 34 | ADC1_CH6;**必须用 ADC1**(ADC2 与 WiFi 冲突),输入专用脚 |
| 羽闭合微动开关 ×8 | 2, 4, 13, 14, 15, 27, 32, 33 | INPUT_PULLUP,开关闭合到 GND;静态背板布线,不跨关节 |
| 预留(不接) | 12 | **禁用**:MTDI strap,上拉会选错 flash 电压导致启动失败 |
| 预留 [v2] | 同开关 8 脚 | 换挂钩触摸电极(电容检测复用,替换微动开关) |
| 预留 [v2] | I2C1(Wire1) | 25/26 现被舵机占用,启用时挪舵机;接第二颗 APDS 等同址器件 |

**strap 铁律**:0/2/5/12/15 上电瞬间的电平决定启动模式——开关类负载选"闭合=拉低"极性,12 永远不接上拉。

## 2. 感知脑 S3(人体状态)

| 功能 | GPIO | 备注 |
|---|---|---|
| I2C0(全部传感器) | SDA=8, SCL=9 | 400kHz |
| UART1 → 动作脑 | TX=17, RX=18 | 115200,协议见 firmware/protocol.md |
| IMU 中断 | 4 | 姿态就绪/运动检测 |
| PPG 中断 | 5 | MAX30102 |
| ToF 中断 | 6 | VL53L1X |
| 电量计告警 | 7 | MAX17048 ALRT |
| 板载 WS2812 | 48 | 状态灯:绿=正常 蓝=BLE 黄=低电 红=故障 |
| 预留 | 10–14, 21 | 大腿 IMU(步态,Phase 3)、扩展触觉 |

**S3 安装**:腰骶背板内侧,IMU 板轴 X 沿脊柱、Y 指向左肩(写进背板结构图);PPG/温湿引线沿肩带/腰带走,用 JST-SH 1.25 连接器可拆。

## 3. I2C 地址总表

| 器件 | 总线 | 地址 | 冲突 |
|---|---|---|---|
| MPU6050 / ICM-42688 | S3 | 0x68(AD0=GND) | 无 |
| MAX30102 | S3 | 0x57 | 无 |
| SHT40 ×2 | S3 | 0x44 ×2 | **同址**:分两条总线或用 I2C mux;简化方案 = 贴身那只用 SHT40、翼外那只用 SHT31(0x45) |
| VL53L1X | S3 | 0x29 | 无 |
| MAX17048 | S3 | 0x36 | 无 |
| APDS-9960 | ESP32 | 0x39 | 无(动作脑独立总线) |

## 4. 供电与共地

```
电池 1S(Phase 1 桌面调试)/ 2S(Phase 2 待定)
 ├─ 5V/3A 同步 DC-DC ──┬─ 舵机 ×4(每侧电源端 470–1000μF 电解 + 100nF 陶瓷)
 │                     └─ 风扇 ×2(MOSFET 低边开关)
 └─ 3.3V LDO ── ESP32 + S3 + 全部传感器

共地铁律:所有轨在 DC-DC 输出端单点汇接(star ground),舵机电流不得流经逻辑地线
线径:舵机轨 ≥22AWG,跨关节线一律 U 形服务环(+15mm)
```

Phase 1 的 MT3608 仅桌面调试用;2S 构型直接 buck 出 5V,效率与浪涌都优于 1S boost(开放问题,拍板进 ADR 0003)。
